# Hat Hair Toggle

Toggle how hair is displayed under your current hat by right-clicking the hat equip slot (rebindable). This mod works on any content patcher hat.

The value persists even when you take your hat off and even if you uninstall this mod, but it is reset to the base value if you put the hat into a dresser.

Whether your hat will actually hide your hair is a combination of the hat's properties and the hairstyle's metadata. This mod changes the hat's hair mode between one of 3:
- Hat Hair: use the hat specific hair
- Normal Hair: use the base hair
- No Hair: hides the hair completely

The changed draw mode persists even when you take your hat off and even if you uninstall this mod, but it is reset to the base value if you put the hat into a dresser.

## Configuration

- `ToggleKey`: Change the toggle key. Default is `MouseRight` and `LeftStick`.
